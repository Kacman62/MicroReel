# MicroReel
A 3D printed way to store SMD tapes components

# What is it?

I've always struggled to find a good way to store SMD component tapes. So I decided to make MicroReel, a small and cheap 3D printed solution to store and organize tapes. It includes an easy load and unload slot, an open side to reduce weight, time and to see the capacity, and the modules lock together with a 6mm dovetail. The small version works is 16 grams, takes under an hour, and holds about 250 components and the large is about 25 grams, takes a little over an hour, and works for 500+ reels. Currently it is designed for 8mm tapes, but will be updated soon. 
Tested and printed on Bambu A1 with OrcaSlicer.
