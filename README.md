# MicroReel
A 3D printed way to store SMD tapes components

# What is it?

I've always struggled to find a good way to store SMD component tapes. So I decided to make MicroReel, a small and cheap 3D printed solution to store and organize tapes. The small version works for about 250 components and the large works for 500+ reels. Currently it is designed for 8mm tapes, but will be updated soon.
